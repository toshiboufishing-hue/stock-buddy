相棒 STOCK v0.2

今回の変更
- 保有株の手動登録を実戦向けに更新
  - PayPay証券 / moomoo証券 / その他
  - 日本株 / 米国株
  - 銘柄名 / コード / 数量 / 平均取得単価 / 現在値 / メモ
  - 登録後の編集・削除
- 監視銘柄（化け株レーダー）の手動登録
- アプリ起動と同時に「起動時調査」を自動開始
- 保有株＋監視株を毎回自動で調査対象に整理
- 損益から警戒・利確・保有継続・待ちを仮判定
- 外部AIへ渡すための「AI調査文」を自動生成し共有可能
- v0.1のサンプル銘柄は移行時に除外
- Service Workerをv0.2用に更新し、古いキャッシュを削除

重要
GitHub Pagesは静的サイトなので、APIキーや証券ログイン情報を安全に置けません。
そのためv0.2の「起動時AI調査」は、
  1. 登録銘柄を自動確認
  2. 前回との差分確認の準備
  3. 損益・警戒ラインのローカル仮判定
  4. 外部AI調査用プロンプトの生成
までを自動実行します。

ニュース / IR / リアルタイム株価 / 本物のAI Web調査の完全自動取得はまだ未接続です。
有料クラウド導入前に、まず無料構成で判断ロジックと運用成績を育てる方針です。

更新方法
GitHubの stock-buddy リポジトリ直下に、このフォルダ内の
index.html / styles.css / app.js / manifest.webmanifest / sw.js / README.txt
を上書きアップロードしてください。
