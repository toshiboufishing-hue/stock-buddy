相棒 STOCK v0.1 試作1号

目的:
- 少額のお小遣い運用をAIで補助
- 普段は見なくても、必要な時だけ通知
- 保有株 / 化け株レーダー / SNS銘柄判定を簡単UIで確認

現時点で動くもの:
- PayPay証券 / moomoo証券を区別した保有株登録
- ローカル保存
- 5段階AIシグナルの試作表示
- 化け株レーダーの試作画面
- SNS投稿の簡易ルール判定
- ブラウザ通知テスト
- PWA用manifest / service worker

まだ接続していないもの:
- moomoo公式APIによる自動保有株同期
- PayPay証券の保有株自動取込
- リアル株価 / 出来高 / ニュース / IR / SNSデータ
- OpenAI等を使った本物のAI分析
- サーバー常時監視
- 専用通知音付きプッシュ通知
- 自動売買

注意:
この版の銘柄・価格・AI点数はすべてサンプルです。投資判断には使用しないでください。
